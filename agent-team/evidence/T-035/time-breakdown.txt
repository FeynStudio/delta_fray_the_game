Where the time goes: the lines added inside the T-034 commit-graph test. On win32 they run 2 names (GIT_TEST_COMMIT_GRAPH, git_test_commit_graph) x 3 values (1, true, yes) = 6 cases, each one plain-git liveness call and one checkHandoff. checkHandoff runs git with execFileSync, so it blocks the event loop of the whole concurrent suite while it runs; its time adds to the file time almost one for one. The 3 new gitEnv table tests take under 1 ms each. On Linux the fixture loop runs 3 cases (upper case only), so the cost there is about half (not measured; no Linux run in this task).
