## Coordinator choices (technical, not human decisions)
- Decision on expected/: not needed. The checked results (the named true/false keys of render, input and turns) are computed as today; only the state of the page at the moment of each screenshot changes. A capture that is not in its wanted state throws an error naming the file (T-008's phaseShot pattern), which already fails the run without a new key.
- No src/ change. The freeze is done from the page through what the browser and the debug API already offer (stop the page's loop from scheduling itself, set the state through __game.setState, redraw). How exactly is the owner's choice; the capture-blink.mjs example shows one way.
- One capture helper in scripts/smoke.mjs, used by every screenshot the script saves (the existing ones and those added by T-017 and T-020): freeze the loop, set state.clock to one fixed value named once in the script, redraw, read the state, take the screenshot, read the state again. The two readings must be deep-equal, and state.clock must equal the fixed value; otherwise the helper throws an error naming the file.
- The fixed clock value is chosen so that a spawn-protected ship is clearly visible (protectionAlpha of at least 0.75; with config.protectionBlinkMs read from the page, not hard-coded).
- Gauge readings in the three phase screenshots: power is set to 0.6 before the first Space (so the power screenshot shows a 60% bar and the two direction screenshots a locked distance of 60% of maxMove); the needle is set to 30 in the two direction screenshots. The phase and backward checks of T-008 stay.
- The checked results keep running on a live loop where they do today; only the capture is frozen. The check "a real Space keypress locks distance" and the other input results are not changed.
- Screenshots that show something moving on purpose (T-017's mid-flight and explosion captures) keep their own state set-up and checks; the helper only adds the frozen loop and the fixed clock around them. If T-017's checks need a clock value of their own, that value is fixed in the script too.
