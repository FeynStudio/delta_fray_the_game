## Coordinator choices (technical, not human decisions)
- How blank is detected, without a new dependency and without a second `p.screenshot()` call: an in-page probe that decodes the saved PNG bytes, not the canvas. fixedShot passes `png.toString('base64')` to a new probe on the same page `p` after the "after" state reading; the probe turns it into bytes (atob), a Blob of type image/png, decodes it with createImageBitmap, draws it on a detached canvas, reads getImageData, and returns its findings. Reading the PNG bytes matters: the T-047 black file may have come from a capture taken while the canvas held a correct frame, so a canvas probe could pass it. Node-side decoding is ruled out by the smoke-shape guard (no new import, no dynamic import of a Node module); a byte-size threshold on the PNG is ruled out because it is not a definition of blank.
- Rule: a capture is blank when, for at least one ship colour COLORS.ships[0] or COLORS.ships[1], no pixel of the decoded image is within 48 of it in each of red, green and blue (the scorePixelsProbe tolerance). Every capture draws both scores in their ship colours (drawScores, every frame), so a real capture always has both colours; the all-black T-047 file has neither. The probe reads COLORS with `import('/src/render.js')` (allowed by the smoke-shape guard).
- Result: a blank capture adds one entry to fixedShot's problems list, so the run fails through the existing `<file>: <problems>` error (exit 1, `{ "error": ... }` in the result JSON, FAIL in verify.sh), and the text names each missing colour, for example `capture is blank: no pixel within 48 of ship colour #4fd1ff (player 1)`. No result key is added, so expected/*.json is unchanged. A PNG the page cannot decode fails the run too (the probe's error reaches the caller as `page error: ...`).
- Names: the probe's name must not contain `exec` (guard line 58); every new line is comment-free; no console call (use the problems list).
- Out of the check, on purpose: retrying a blank capture (it would hide the fault this check exists to show), and finding why the T-047 capture was black.
