## Goal
An enemy ship that has not moved since it last spawned (including at the start of the game) survives being swept by an enemy move; once it makes its own move it can be destroyed as before.

## Coordinator interpretation of A2 (technical choices, not human decisions)
- Coordinator's choice: each ship gets a boolean field `unmovedSinceSpawn`. `createInitialState` and `endTurn` (for a respawned ship) set it to true; `applyMove` sets it to false on the mover whenever it accepts the move (a refused move over maxMove returns the state unchanged, so the flag stays). Living ships that do not move keep their value.
- Coordinator's choice: a new pure, exported `isSpawnProtected(state, i)` in src/rules.js returns true only if ships[i] is alive, has `unmovedSinceSpawn === true`, and its x and y equal config.spawns[i] within 1e-9 (read at call time). In normal play only a ship's own move changes its position, so the position part never changes the outcome; it only stops a test state teleported through setState from keeping protection (the turnsProbe trap above). T-010 uses this function.
- Human decision (2026-11-09, see Decisions): any move that applyMove accepts ends protection, including a distance-0 launch (power reading exactly 0), so a player cannot stay protected by launching zero-length moves. This was the coordinator's earlier choice; the human confirmed it.
- Note for T-009 (DRAFT): T-009 may change how a backward move turns the ship. A backward move is an accepted move like any other, so it ends protection either way; this rule does not change.
- Unchanged: protection only stops a ship being destroyed by an enemy's swept area. A protected ship that moves and reaches the wall still dies (wall rule of 2026-11-09). Ships without the field (all scenario states) are not protected.
