## Coordinator choices (technical, not human decisions)
- Only tests/game.test.js changes. In its `before` hook, console.info is replaced for the length of the import by a function that records its arguments, and put back right after the import (also if the import throws).
- One new test asserts what was recorded: exactly one call, whose first two arguments are '[game]' and 'game started', and whose third argument is an object with a ships array of length 2. That keeps the start-up log covered instead of just hidden.
- console.warn and console.error are not touched: a warning or an error during the tests must still show.
- No comment in the test file (no-comments guard).
