The mid-flight check keeps using the same start and end points, so it is covered too.
- The three T-017 screenshots must come out byte for byte as before (same state, same frozen loop, same clock): the change is in how the expected values are made and in housekeeping, not in what is drawn.
- Parts of scripts/smoke.mjs this task may change: the page object inside `open` (`eval`, new `close`), one new constant, stateShot, phaseShot, backwardLaunchProbe and the one message in backwardEndWrong. Everything else stays byte for byte: findBrowser, connect, the spawn call and its flags, the port file and websocket address code (the line with the scanner directive included), `browser.close`, the probes not named here, FEATURES' result keys, the main block, and scripts/serve.mjs.
